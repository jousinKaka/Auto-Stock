# 에이전트 3 — 위험 및 현금 여력 진단

## 역할

`agent3_risk.py`의 동작을 설명하고 보존하는 작업 지침입니다. 에이전트 3은 현재 전략 상태와 가격 자료를 바탕으로 현금 소진, 매수 여력, 평가손익, 변동성 및 레버리지 변동성 끌림의 추정치를 요약합니다.

## 입력과 결과

- 입력은 에이전트 2의 `StrategyState`, 현재 가격, 선택적인 최근 일별 종가입니다.
- 결과 `RiskAssessment`에는 위험 등급, T값, 현금 소진율, 예상 매수 여력, 평가 손익률, 연환산 변동성 및 변동성 끌림 추정치가 포함됩니다.
- 리버스 모드, 높은 T값, 낮은 현금 여력 또는 큰 평가 손실에 따라 경고와 점검 항목을 Markdown으로 제공합니다.
- 충분한 최근 종가가 없을 때의 변동성 값은 실제로 관측한 결과가 아니라 코드상 기본 추정값일 수 있습니다. 데이터 출처와 계산 상태를 실제 관측값처럼 표현하지 않습니다.

## 지켜야 할 경계

- 이 에이전트는 진단 및 알림 역할입니다. 주문 가격·수량을 만들거나 전략 상태를 변경하거나 주문을 제출하지 않습니다.
- 위험 등급과 안내 문구는 투자 권유, 손실 방지 보장 또는 수익 보장으로 표현하지 않습니다.
- 계산값이 추정치이거나 입력 자료가 제한된 경우 그 한계를 숨기지 않습니다.
- 전략 규칙을 설명하는 문구를 바꾸더라도 실제 규칙을 에이전트 3의 판단으로 대체하지 않습니다. 전략 로직 변경은 [공통 지침](./AGENTS.md)의 확인 절차를 따릅니다.

## 수정 시 확인

- T값·분할 수·현금·평단이 다른 경계 상태에서 위험 등급과 경고가 합리적으로 생성되는지 테스트합니다.
- 변동성 자료가 없거나 충분하지 않은 경우 관측값과 기본 추정값의 구분이 명확한지 확인합니다.
- 에이전트 3의 결과가 에이전트 2의 주문 계산이나 에이전트 7의 제출 여부에 몰래 영향을 주지 않는지 확인합니다.
