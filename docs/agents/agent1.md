# 에이전트 1 — 체결 원장 및 투자 일지

## 역할

`agent1_journal.py`의 동작을 설명하고 보존하는 작업 지침입니다. 에이전트 1은 일별 계좌·체결 상태를 JSON 원장에 기록하고, 투자 일지 Markdown 보고서를 생성합니다.

## 입력과 결과

- `DailyExecutionRecord`에 기준일, 종목, 회차, T값, 모드, 보유량, 평단, 현금, 체결 수량·금액, 손익, 계좌 평가액, 메모를 기록합니다.
- 선택적으로 토스 계좌 보유량·USD 매수 가능 금액, 정산 완료 주문 ID를 기록합니다.
- 선택적으로 에이전트 2의 주문표와 에이전트 3~6의 요약을 보고서에 포함합니다.
- 기록은 설정된 JSON 파일에 날짜 순으로 저장하며, 같은 날짜 기록을 갱신하면 기존 날짜 항목을 대체합니다.
- 보고서는 설정된 보고서 폴더에 `{날짜}_{종목}_report.md` 형식으로 저장합니다.

## 지켜야 할 경계

- 실제 증권사 체결 내역과 전달받은 계좌 값을 그대로 기록합니다. 확인되지 않은 체결이나 계좌 숫자를 만들어 넣지 않습니다.
- 전략 판단이나 주문 가격·수량을 이 에이전트에서 계산하지 않습니다. 주문표는 에이전트 2가 생성한 결과를 전달받아 표시합니다.
- 전략 장부상 보유량과 증권사 실제 보유량, 전략 현금과 증권사 매수 가능 현금을 혼동하거나 하나로 덮어쓰지 않습니다.
- 원장 저장 형식·필드 의미를 바꾸는 경우 기존 JSON 기록의 호환성과 데이터 보존을 확인합니다. 기록을 임의로 초기화하거나 삭제하지 않습니다.
- 보고서에 수치가 있으면 해당 기록 데이터에 근거해야 합니다. 손익이나 계좌 상태를 추정으로 확정 표시하지 않습니다.

## 수정 시 확인

- 같은 날짜 기록의 갱신, 날짜 정렬, 한글 JSON 인코딩, 보고서 저장 경로를 확인합니다.
- 선택 필드가 없어도 보고서가 올바르게 생성되는지와 매매 주문표를 생략하는 호출 경로를 검증합니다.
- 전략 관련 필드의 의미를 변경해야 한다면 저장소의 [공통 지침](./AGENTS.md)에 따라 공식 규칙 참고 페이지를 먼저 확인합니다.
