# 에이전트 4 — 거시경제 지표 관찰

## 역할

`agent4_macro.py`의 동작을 설명하고 보존하는 작업 지침입니다. 에이전트 4는 Yahoo Finance에서 거시·시장 지표의 완료된 일봉을 조회해 관측값과 제한적인 국면 분류를 보고합니다.

## 입력과 결과

- 조회 지표는 미국 10년물 금리(`^TNX`), 달러 인덱스(`DX-Y.NYB`), VIX(`^VIX`), 나스닥 100(`^NDX`), S&P 500(`^GSPC`)입니다.
- 금리·달러·VIX는 국면 판정에 필요한 지표입니다. 하나라도 빠지면 `DATA_UNAVAILABLE`을 반환하고 국면 또는 압박 수준을 판정하지 않습니다.
- 시장 시간대 기준 진행 중인 일봉을 제외하고, 조회된 실제 값만 표시합니다. 데이터 기준일과 누락·조회 실패 사유도 보고합니다.
- 출력은 `MacroAnalysisResult`이며 Markdown 보고서와 아침 알림·일일 일지에서 사용될 수 있습니다.

## 지켜야 할 경계

- 누락되거나 조회에 실패한 값을 예시 숫자, 고정 기본값 또는 이전 결과로 대체하지 않습니다.
- 거시 지표 분석은 관찰 정보이며 매수·매도 신호나 주문 적합성 판단이 아닙니다.
- 분석 실패를 감추지 않고 결과에 상태와 이유를 남깁니다. 거시 분석의 실패를 주문 실행 전체의 실패로 바꾸지 않도록 분석과 주문 경계를 유지합니다.
- 지표 해석이나 국면 임계값을 변경할 때 출처와 해석 한계를 명확히 하고, 주문 계산 입력으로 연결하지 않습니다.

## 수정 시 확인

- 전체 조회 실패, 일부 필수 지표 누락, 보조 지표 누락, 유효한 실제 데이터 입력의 각 경우를 테스트합니다.
- 완료 일봉 기준일과 보고서·알림에 표시되는 `DATA_UNAVAILABLE` 상태를 확인합니다.
- 누락된 데이터가 정상적인 국면 또는 낙관적 요약으로 보이지 않는지 검증합니다.
