# 에이전트 5 — 반도체 업종 기술 지표

## 역할

`agent5_industry.py`의 동작을 설명하고 보존하는 작업 지침입니다. 에이전트 5는 SOXX의 완료된 일봉 가격을 사용해 반도체 업종의 기술적 추세 지표를 계산합니다.

## 입력과 결과

- Yahoo Finance에서 SOXX의 일봉 가격을 조회하며, 완료된 거래일 데이터만 사용합니다.
- 출력 `SemiCycleSnapshot`에는 기준 거래일, 가격 변동률, RSI(14), 20·50·200일 이동평균, 기술 추세 구분, 데이터 품질 메모가 포함됩니다.
- 200일 추세에 필요한 데이터가 충분하지 않거나 조회에 실패하면 지표를 만들지 않고 데이터 부족 또는 `DATA_UNAVAILABLE` 상태를 표시합니다.

## 지켜야 할 경계

- SOXX는 업종 기술 흐름을 관찰하기 위한 지표입니다. 이를 SOXL의 실시간 구성 종목·비중, 기업 실적 분석 또는 SOXL 주문 신호로 표현하지 않습니다.
- 조회 실패 시 예시 가격이나 추세를 대신 생성하지 않습니다.
- 추세 분류는 계산된 가격과 이동평균의 배열을 요약할 뿐, 매수·매도 권유나 수익 보장이 아닙니다.
- 이 에이전트의 출력이 에이전트 2의 주문 가격·수량 계산에 들어가지 않도록 분리합니다.

## 수정 시 확인

- 완료 일봉만 쓰는지, 지표 산출에 필요한 표본 수를 확인하는지 테스트합니다.
- 상승·조정·하락·혼합 추세 경계 및 데이터 부족·조회 실패를 검증합니다.
- 보고서에 분석 범위와 주문 신호가 아님을 계속 표시합니다.
