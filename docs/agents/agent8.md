# 에이전트 8 — Google Sheets 계좌 현황 동기화

## 역할

`agent8_sheets_sync.py`는 토스증권 계좌의 보유 종목, USD 매수 가능 현금, 현재가를 조회해 지정된 스프레드시트의 현재 계좌 표를 갱신합니다. 평일 09:00 KST 아침 루틴에서 에이전트 7의 계좌 정산과 일일 리포트 생성 후 실행합니다.

## 입력과 기록 범위

- 토스 계좌의 보유 종목 티커, 수량, 평균 매수가, USD 매수 가능 금액과 종목별 현재가를 사용합니다.
- A~F에는 티커, 현재가, 평균 매수가, 수량, 평가 금액, 계좌 총액 대비 비중을 기록합니다.
- J에는 종목별 수익률을 소수 비율로 기록합니다. 예를 들어 `0.0451`은 시트에서 백분율 서식이 적용될 경우 `4.51%`로 표시됩니다.
- 예수금 행에는 A열 이름과 E열 현금, F열 비중을 기록합니다.
- G~I 및 L~M 등 지정된 범위 밖의 셀은 변경하지 않습니다.
- `GOOGLE_SHEETS_TICKER_ROWS`는 티커마다 대상 행을 명시합니다. 이 매핑은 기존 시트의 종목별 G~I 값/수식과 연결을 보존하기 위한 필수 설정입니다.
- 동주(키움) 탭에서 확인한 현재 행 대응은 `NVDU:5,SOXL:6,TQQQ:7`, 예수금은 10행입니다. 계좌 보유 종목이나 시트 행을 바꾸면 이 매핑도 함께 수정하세요.
- 현재 비중은 USD 보유 종목 평가액과 USD 매수 가능 현금 합계를 분모로 계산합니다. KRW 현금이나 다른 계좌는 이 합계에 포함되지 않습니다.

## 안전 경계

- 연동은 기본 비활성화입니다. 설정이 불완전하면 쓰기 요청을 보내지 않고 구체적인 오류를 발생시킵니다.
- 계좌 응답, 수량, 가격, 평균 매수가, 현금 또는 시트 권한이 유효하지 않으면 오래된 값이나 예시값으로 대체하지 않습니다.
- 매핑되지 않은 새 보유 티커가 있으면 어느 행에도 임의로 쓰지 않고 중단합니다. 티커와 행을 검토한 뒤 매핑을 갱신하세요.
- 등록한 티커의 보유량이 0이 되면 해당 행의 A~F와 J를 지웁니다. 다른 열은 지우지 않습니다.
- Google Sheets API를 Google Cloud에서 활성화하고, 서비스 계정 이메일을 시트 편집자로 공유해야 합니다. 서비스 계정 키와 토스 API 인증 정보를 저장소에 넣거나 로그에 출력하지 않습니다.
- Agent 8은 주문을 생성하거나 제출하지 않으며 무한매수 전략 계산도 변경하지 않습니다.

## 설정 및 검증

- `GOOGLE_SHEETS_ENABLED`, 스프레드시트 ID, 탭 gid, 서비스 계정 JSON 파일 경로, 티커별 행 매핑, 예수금 행을 설정합니다.
- 서비스 계정 이메일을 대상 스프레드시트 편집자로 공유해야 합니다.
- 첫 실계정 실행 전에 행 매핑과 G~I의 목표값/수식 대응을 확인하고, 테스트에서는 시장가·평균가·수량·현금으로 평가액과 비중을 독립 계산해 검증합니다.
