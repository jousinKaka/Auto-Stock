# 에이전트 6 — 반도체 기업 및 실적 일정 관찰

## 역할

`agent6_fundamental.py`의 동작을 설명하고 보존하는 작업 지침입니다. 에이전트 6은 미리 정한 반도체 기업 관찰 목록의 가격과 Yahoo Finance 실적 캘린더 정보를 모아 요약합니다.

## 입력과 결과

- 현재 관찰 목록은 NVDA, AVGO, AMD, QCOM, TSM, MU, AMAT, INTC입니다.
- 종목별 완료된 가격 데이터와 1일 변동률, 확인 가능한 다음 실적일, EPS·매출 평균 추정치, 점검할 핵심 지표를 반환합니다.
- 출력 `SOXLConstituentsAnalysis`는 관찰 목록의 범위, 조회 시각, 가격 기준 거래일과 데이터 품질 참고를 포함합니다.
- 실적 일정·컨센서스가 없거나 조회에 실패하면 값을 `N/A`에 해당하는 빈 값으로 두고 이유를 남깁니다.

## 지켜야 할 경계

- 관찰 목록은 SOXL의 실시간 편입 종목이나 실제 비중이 아닙니다. 그렇게 표현하지 않습니다.
- EPS·매출 숫자는 공급처의 평균 추정치이며 실제 실적이나 확정 전망으로 취급하지 않습니다.
- 데이터가 없으면 예시 숫자, 임의의 실적일 또는 추정치를 만들어 채우지 않습니다.
- 이 분석은 정보 참고용이며 에이전트 2의 주문 가격·수량 계산에 사용하지 않습니다.
- 사용자 요청에 따라 코드에 미저장 변경이 있을 수 있으므로, 문서를 갱신할 때 현재 구현을 먼저 확인하고 사용자 변경사항을 보존합니다.

## 수정 시 확인

- 종목별 가격 조회 실패와 실적 캘린더 형식 차이, 값 누락, 지난 실적일 및 향후 실적일을 확인합니다.
- 미확인 값을 빈 값으로 표시하고 데이터 품질 사유를 남기는지 테스트합니다.
- 관찰 목록과 보고서 안내에서 SOXL 실제 편입·비중이라고 오인할 표현이 없는지 점검합니다.
