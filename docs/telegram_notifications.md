# 텔레그램 계좌 알림

아침 계좌 알림에는 T값, 보유량, 평단가, 평가손익, 전략 현금, 증권사 보유량·현금, 총자산의 증감을 괄호로 표시합니다. 비교 대상은 같은 종목의 현재 날짜보다 앞선 가장 최근 저장 기록입니다. 같은 날짜에 다시 실행해도 당일 기록과 비교하지 않으며, 주말 등 기록이 없는 날에는 직전 기록을 사용합니다.

현재가의 금액·백분율 등락은 저장 기록의 현재가와 비교하지 않고, 이번 실행의 기준 종가(`prev_close`)와 비교합니다. 주문 계산에 사용하는 가격은 변경하지 않습니다. 평가손익은 금액 증감과 수익률 차이(%p), 총자산은 금액 증감과 변화율을 함께 표시합니다. 비교 값이 없으면 해당 증감을 생략하고, 기준 금액이 0 이하이면 변화율을 생략합니다.

계좌 메시지에는 미리보기 제목이나 하단 이탤릭 안내를 넣지 않습니다. 기업·실적 분석은 Markdown 표를 종목별 카드로 바꾸고 출처는 클릭 가능한 링크로 전송합니다. 메시지가 길면 카드 사이에서 나눠 보냅니다.

수동 미리보기 스크립트는 직접 실행할 때만 실제 메시지를 발송합니다. `test_telegram_account_preview_manual.py`의 금액은 2026-10-28 확인용 예시이며 자동 알림에는 사용하지 않습니다. 자동 테스트는 발송 함수를 모의 처리합니다.
